# Security Policy

Report security vulnerabilities privately to the project maintainers. Do not disclose API keys, proof-of-concept payloads, or exploit details in public GitHub issues.

Security reports should include the affected version, reproduction steps, impact, and any suggested mitigation. The project aims to acknowledge valid reports within 72 hours.

In scope: API-key leakage, SSRF bypasses, unsafe redirect handling, authentication bypasses, and remote code execution.
